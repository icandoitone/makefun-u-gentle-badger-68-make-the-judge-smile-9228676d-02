## The entry

> This morning the rain started just as I reached the market, and a stranger held his umbrella over my basket of eggs — then apologised for smelling of fried shallots.

## How it works

`main.py` is a deterministic Python 3.13 program (standard library only, no network, no randomness). It writes the single entry line to `/output/entry.txt`, or to the path in the `OUTPUT_PATH` environment variable when set. Before writing, it asserts the line is 1–200 characters and a single non-blank line, so an invalid entry fails loudly instead of being written.

Run it:

```sh
python3 main.py
```
